 # Student Results Dashboard

### 1. Project Title
Student Results Dashboard – Student Performance Display System

### 2. Project Description
Student Results Dashboard is a responsive web application designed to display student examination results in a clear and organized format. The dashboard shows student information, subjects, scores, and pass/fail status with color codes. It also includes a print functionality for easy result documentation. The project aims to provide a simple and organized result viewing experience.

### 3. Features
- Displays student full name: AKINDELE OLUWATOBI AUGUSTINA
- Shows subjects and scores in a table format
- Pass status displayed in Green and Fail status in Red
- Print Result button to print the result dashboard
- Responsive and modern user interface
- Mobile-friendly navigation and layout

### 4. Technologies Used
- HTML5: Structures the dashboard content
- CSS3: Styles the dashboard and makes it responsive
- JavaScript: Adds print functionality and interactivity

### 5. How to Run the Project
- Download or clone the project repository from GitHub
- Open the project folder in Visual Studio Code
- Ensure that index.html, style.css, and main.js are in their correct locations
- Open index.html in your web browser
- Alternatively, install the Live Server extension in VS Code, right-click index.html, and select Open with Live Server
